# TTD Darshan Auto-Fill Pro

A Google Chrome extension designed to automatically fill pilgrim details, click continue, and reach the payment page for TTD Special Entry Darshan and Special Sevas booking. This extension saves you precious time during the booking process.

Built and developed by **Siva Ganesh Adapa**.

## Features
- ⚡ **Auto-Fill Details**: Saves and automatically inputs pilgrim details (Name, Age, Gender, ID, etc.).
- 🔄 **Universal Support**: Works on both standard Special Entry Darshan (SED) and Special Sevas.
- 🎨 **Clean UI**: A beautiful, modern interface matching the TTD official branding.
- 🗂️ **Accordion Layout**: Keeps your view clean by automatically minimizing completed cards.
- 🔒 **Privacy Focused**: All your data is saved locally on your own computer.

---

## 🛠️ How to Install (100% Free)

Since this extension is hosted on GitHub, you can easily install it on Google Chrome using "Developer Mode".

**Step-by-step Installation Guide:**

1. Scroll to the top of this page, click the green **"<> Code"** button, and select **"Download ZIP"**.
2. Extract (unzip) the downloaded folder on your computer.
3. Open Google Chrome and type `chrome://extensions/` in the URL bar, then hit Enter.
4. Turn **ON** the **"Developer mode"** switch in the top right corner of the screen.
5. Click the **"Load unpacked"** button in the top left.
6. Select the extracted folder (make sure to select the folder containing `manifest.json`).
7. The extension is now installed! You can pin it to your toolbar by clicking the puzzle piece icon 🧩 in Chrome.

## 📖 How to Use
1. Open the extension and save your pilgrim details in the **Pilgrims** tab.
2. Go to the TTD website, log in, and select your booking date & slot.
3. Select the number of pilgrims and click **Continue**.
4. When the pilgrim details form appears, open the extension and click **Start Auto-Fill**.
5. The extension will automatically fill out all the fields for you!
